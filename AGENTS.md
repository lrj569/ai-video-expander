# Project Instructions

## Development Workflow

- The step-by-step procedure, reading order and acceptance are defined in the main repository's SOP: `D:\项目\池源\ai-website-builder\docs\workflows\three-page-interface-development-sop.md`. Follow it.
- Development stage scope: the Home, Guide and Pricing pages, their media, and the llms public index. Do not configure Clerk, a domain or a support email in development.
- Locked SEO documents are the only authority for page copy. Do not invent, rewrite, shorten or hide locked copy.
- Page design comes only from `design-system/<slug>/MASTER.md` and `design-system/<slug>/pages/<page>.md`, generated by ui-ux-pro-max. Do not create a DESIGN.md.
- Hero structure follows only the frozen sketch from the main SOP; no human approval is required. Hero colour, type and radius come from MASTER.md.
- Do not modify files in the main repository.

## Astro Engineering Standard

- Before adding or changing any route, metadata, Island, crawler rule, sitemap behavior, or performance behavior, read `docs/astro-project-development-standard.md`.
- Before changing SSR data loading, client hydration, caching, media loading, third-party scripts, or above-the-fold behavior, read `docs/astro-ssr-performance-standard.md`.
- Before adding or changing a React island or shared account state, read `docs/astro-islands-architecture.md`.
- Default to server-rendered HTML plus the smallest possible React islands.
- Public SEO content must not depend on client-side fetching.
- Register every real route in `src/config/page-policies.json`. Do not create speculative SEO routes.

## Page Rules

- Hero excludes navigation and is implemented from the frozen sketch.
- Pricing and generator forms reuse the existing components and shared configuration. Preserve checkout behaviour.
- The navigation login button may change only its background and text colour. Do not modify the Footer bottom navigation.
- Do not invent sales statistics, performance results or price promises.
- Each project chooses its own font family, sizes and weights from its design tokens. Import its selected self-hosted package CSS only through `src/styles/project-fonts.ts`, which BaseLayout loads once.
- When rendering locked Markdown, use `normalizeLockedCopy` from `src/lib/locked-copy.ts` before parsing; preserve the locked copy and render public headings only once.

## Verification

- Quality gates are run through the external gate; sub-agents do not issue LOCAL_READY or RELEASE_READY.
- Run `npm run check`, `npm run verify:islands`, `npm run build` and `npm run verify:routes` when the change requires them. Repair failures; never weaken thresholds or validators.
- Local checks do not prove deployment, authentication, generation, payment or production Core Web Vitals.
