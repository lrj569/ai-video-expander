# AI Video Expander Hero 布局草图

## 竞品证据摘要

2026-11-24 11:09:54（中国标准时间），观察 https://seedreams.net/ 的 1440×900 和 390×844 页面。取证位于 `evidence/capture.json`、`evidence/desktop-top.png`、`evidence/mobile-top.png` 及两端 Hero 区域与结构文件。桌面工作区左列从 x112 开始、宽约 497，右列从 x633 开始、宽约 695。移动端左右各留 16 px，先设置表单，后媒体与缩略图。

| ID | 元素 | 观察事实 | 任务作用与取舍 | 本站处理 |
| --- | --- | --- | --- | --- |
| E01 | 主标题 | 桌面居中且切成两行视觉层级，移动端居中重排 | 先识别工具；独立口号会占用操作空间 | 顶部居中使用锁定 H1，重点用主题色或字重区分 |
| E02 | 副标题 | 位于 H1 和工作区之间，桌面约三行 | 解释工具输出，让用户决定是否上传 | 使用锁定副标题，保持在表单之上 |
| E03 | 设置表单 | 桌面左列、移动端先出现，设置按字段逐行排列，底部提交 | 先完成输入与选择，有利于连贯操作 | 将左列图片设置转译为单视频上传、必填补边描述、目标画幅、画质及输出长度。Hero 内含直接操作的制作入口，省略重复跳转 CTA |
| E04 | 大媒体预览 | 桌面右列顶端和表单对齐，主屏约 16:9，移动端置于表单后 | 辅助理解结果，大图利于观察边缘 | 使用本站素材展示画幅扩展效果。选择案例时，在原位更新媒体及参数，保留用户上传的输入直到主动选择 Try it |
| E05 | 缩略图 | 大图下方一排缩略图，选中项有可见高亮 | 支持快速切换且保留当前选择 | 使用本站案例，保持可点击、可聚焦、可见选中反馈 |
| E06 | 案例标题和操作 | 案例标题叠放在大图下缘 | 体现媒体所代表的任务；文字和视频控件重叠会影响播放 | 放在播放器外下缘的说明行，同时提供 Try it，带入当前案例视频和设置 |

参考 Hero 是静态图片作品切换。两次取证均未出现 Hero 视频，视频帧列表为空。沿用主媒体加缩略图的位置和层级。本站用明确的原片和画幅成品关系表达几何变化，避免用视频的单纯播放代替画幅观察。

## 样式与交互参数

桌面工作区最大约 1216 px，列占比约 41% 与 59%，间隙 24 px。表单内距桌面 24 px、手机 16 px。上传区约 94 px 高，补边文字区约 78 px 高。主操作至少 48 px，参数触控区域至少 44 px。锁定 H1 后一段说明让面板在常见桌面首屏可见。移动端在 820 px 以下做单列。基础表面使用深墨蓝和分层冷灰蓝，重点操作与选中项使用冰青。标题用 Instrument Sans 与冰蓝渐变，形成视频工作台标识。媒体表面保持接近 16:9，目标比例通过播放器内留白容纳，保持视频完整。默认展示三条互异题材，工作台初始没有上传和提示词；比例默认 16:9、画质 720p、时长 5 秒。显示全部六种比例；手机排两行。测试时核对生成结果区域和表单相邻但职责独立。切换案例时用短交叉淡入。鼠标悬停在案例图时提供位置反馈，键盘和减少动态模式保持可操作。

```text
              E01 主标题（锁定 H1）
              E02 副标题（锁定）
┌─ E03 #tool（约 41%） ────────────┬─ E04 案例播放器（约 59%） ──────────┐
│ 上传区：单文件按钮 / 支持拖放      │ 16:9 画布：原片 / 目标版播放         │
│ 选定后同区显示文件、替换和错误     │ 原始画幅关系可查，失败保留封面       │
│ 补边描述：必填多行文本与计数       │ E06 当前案例标题 + Try it           │
│ 目标画幅：六个连续比例选项         │ E05 三个案例缩略图，当前项可见       │
│ 画质和输出时长：分组、已选状态     │                                     │
│ 功能提交按钮 + 内联状态反馈       │                                     │
└──────────────────────────────────┴─────────────────────────────────────┘
焦点顺序：上传 → 补边描述 → 画幅 → 画质 → 输出时长 → 提交 → 媒体 → Try it → 案例。触控无悬停时仍显示操作，键盘焦点清楚，减少动态时只切换状态。
```
