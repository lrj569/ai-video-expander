# Guide

从简短介绍和目录进入教程。锁定正文按序读，桌面 2 列采用左侧粘性目录与右侧 66–72 字符宽正文，手机移为首屏内折叠目录。锚点保留标题能看见的固定导航偏移。主 H1 用全站显示字体，正文字号 16–18px，行距 1.65。复制、Try it 和 FAQ 使用冰青焦点、悬停以及按下反馈，首段和模块只作温和入场。所有正文服务端存在。

| 模块 | 素材与理由 |
| --- | --- |
| Hero 与 Quick Start | 无；开始按钮和短路径更易扫读。 |
| Choose Your Starting Workflow / Prepare Your Inputs / Configure the Sequence | 无，保持条件和选择相邻，以原文顺序使用列表。 |
| Generate / Download / Continue | 无；正文与已锁定控件词对应。 |
| Prompt Examples | 源片小窗与一条目标比例成品对照，起始素材说明、完整提示词、Copy prompt 和 Try it 都保留。移动端排成输入、提示词、成品，成品占主要视觉。 |
| Troubleshooting、FAQ、Final CTA | 无；以故障描述定位，FAQ 可键盘展开。 |
